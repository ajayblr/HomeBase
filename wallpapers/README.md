# Your wallpapers

Put photos in this folder (JPG, PNG or WEBP; landscape 1920×1080 or larger looks best).

On GitHub: open this folder → **Add file → Upload files** → drag your photos in → **Commit changes**.

The next build lists them in `wallpapers.json`, and the TV picks them up within a few hours.
To see them straight away, go to **Launcher options → Background → Your photos** on the TV.
